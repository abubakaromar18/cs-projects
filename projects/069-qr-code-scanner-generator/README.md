# 069 · QR Code Scanner/Generator (Flutter)

**QR Studio** is a cross-platform Flutter app with three tabs:

- **Generate** – build a QR code for plain text, a URL, Wi-Fi credentials, an e-mail, a phone
  number or a contact card. The preview updates as you type, and you can pick the
  error-correction level (L/M/Q/H).
- **Scan** – point the camera at a code. The app recognizes the payload type and shows it as
  labelled fields (SSID / password, name / phone, latitude / longitude, …) with copy buttons.
- **History** – every scanned or saved code, newest first, with search, swipe-to-delete, and
  a tap to show the details and the code again.

The generator does **not** use a QR package. `lib/src/core/` is a from-scratch ISO/IEC 18004
encoder in pure Dart (no Flutter imports). It supports all 40 versions, the four ECC levels and
the numeric, alphanumeric and byte (UTF-8) modes. Scanning uses
[`mobile_scanner`](https://pub.dev/packages/mobile_scanner), which wraps ML Kit (Android) and
Apple Vision (iOS/macOS).

## CS concepts demonstrated

| Concept | Where |
|---|---|
| **Finite-field arithmetic** in GF(2⁸): log/antilog tables, inverses, the primitive polynomial 0x11D | `core/gf256.dart` |
| **Reed–Solomon codes**: the generator polynomial ∏(x − 2ⁱ), polynomial long division as an LFSR, syndromes | `core/reed_solomon.dart` |
| **BCH codes** for the format info (15,5) and **Golay** for the version info (18,6) | `formatInfoBits`, `versionInfoBits` |
| **Bit-level encoding**: mode indicators, variable-width count fields, 10-bits-per-3-digits and 11-bits-per-2-chars packing | `core/segment.dart`, `core/bit_buffer.dart` |
| **Interleaving** codewords across blocks, so a burst of damage is spread across all of them | `QrCode.addEccAndInterleave` |
| **Search/optimization**: the smallest version that fits, a free ECC-level boost, and the mask with the lowest penalty out of 8 | `QrCode.encodeSegment`, `penaltyScore` |
| **Parsing with escapes** (`WIFI:`/`MECARD:` `KEY:value;` grammar), percent-encoding, vCard | `core/payload.dart` |
| **Sealed classes + exhaustive pattern matching** for payload types | `QrPayload`, `PayloadDetails.fieldsFor` |
| **Bounded LRU-style history** with move-to-top, which also debounces repeated detections | `core/history.dart` |
| **Dependency injection** for testability: the camera is swapped out for a fake in widget tests | `ScannerBuilder` |

### How encoding works

```
"HELLO WORLD"
  │ 1. mode = alphanumeric → 0010 | count 000001011 | 11 bits per pair …
  │ 2. version 1 fits at level Q (13 data codewords)
  │ 3. terminator + pad to bytes + 0xEC 0x11 padding
  │ 4. Reed–Solomon: 13 data → +13 ECC codewords, split into blocks and interleaved
  │ 5. draw finders, timing, alignment and the reserved format area
  │ 6. zig-zag the 208 data bits up and down two-column strips
  │ 7. try masks 0–7, score them (runs, 2×2 blocks, finder look-alikes, dark balance)
  ▼ 8. write the BCH-protected format bits for the winning mask
21×21 symbol
```

## Build, run, test

The platform folders (`android/`, `ios/`, `macos/`, …) are generated by Flutter and are
git-ignored.

```bash
cd projects/069-qr-code-scanner-generator
flutter create . --project-name qr_studio --platforms=android,ios,macos
flutter pub get

flutter run                # a connected phone, an emulator, or -d macos
flutter test               # unit + widget tests
flutter analyze
```

You need Flutter 3.22 or newer. Camera access also needs the usual platform setup for
`mobile_scanner`:

- **iOS** – in `ios/Runner/Info.plist`:
  `<key>NSCameraUsageDescription</key><string>Scan QR codes</string>`
- **macOS** – the same key in `macos/Runner/Info.plist`, plus
  `<key>com.apple.security.device.camera</key><true/>` in both `*.entitlements` files.
- **Android** – `minSdkVersion 21` or higher in `android/app/build.gradle`. The plugin
  declares the camera permission itself.

The Generate and History tabs work on every platform. The Scan tab needs a platform with a
camera that `mobile_scanner` supports.

### Encoder only (plain Dart, no Flutter)

```bash
dart run tool/qr_cli.dart "https://dart.dev"           # ASCII art in the terminal
dart run tool/qr_cli.dart --ecl H --pbm wifi.pbm 'WIFI:T:WPA;S:Home;P:secret;;'
dart run tool/qr_cli.dart --bits --mask 3 "HELLO"      # raw 0/1 rows
./tool/run_core_tests.sh                               # core tests + strict analysis
```

### Test status

- **Core unit tests (`test/core/`, 54 tests): passing.** They cover GF(256) laws,
  Reed–Solomon (the generator polynomial from ISO 18004 Annex A, the classic "HELLO WORLD"
  ECC vector, syndromes), the capacity, alignment, format and version tables, mode packing,
  golden symbols, capacity limits at version 40, mask selection, and payload round trips.
  Flutter could not be downloaded in the environment where this was built, so the tests were
  run on the plain Dart SDK (3.14) through `tool/run_core_tests.sh`. That script also runs
  `dart analyze` with strict casts, inference and raw types, which reported no issues.
- **The encoder was also cross-checked against an independent implementation.** 498
  symbols (random numeric, alphanumeric and UTF-8 inputs, all four levels, forced masks,
  versions 1–40) were compared bit for bit with the Python `qrcode` library, with zero
  differences. Every auto-masked symbol in a second set was decoded correctly by ZXing.
  The golden fingerprints in `qr_code_test.dart` came from that check.
- **Widget tests (`test/widget/`, 7 tests) were written but not run there**, because they
  need the Flutter SDK. Run `flutter test` to run them. They replace the camera with a fake
  through `ScannerBuilder`.

## Possible extensions

- **A decoder written from scratch**: binarize a camera frame, find the finder patterns,
  apply a perspective transform, sample the grid, then do Reed–Solomon *decoding*
  (Berlekamp–Massey + Chien search + Forney). `ReedSolomon.syndromes` is already the first
  step.
- **Mixed-mode segmentation**: a dynamic-programming split such as `0123ABCdef` into
  numeric + alphanumeric + byte segments, for smaller codes. Also Kanji mode and ECI headers.
- Export to PNG or SVG and share it, and add a logo overlay at level H.
- Save history to disk (`path_provider` + the existing `toJson`/`fromJson`).
- Scan from an image in the gallery (`MobileScannerController.analyzeImage`).
- Micro QR and rMQR symbols.
