# Data

* `penguins.csv` — Palmer Penguins (Gorman, Williams & Fraser 2014; packaged by Horst, Hill & Gorman),
  from <https://github.com/allisonhorst/palmerpenguins>. Released under **CC0**. `NA` marks a missing value.
* `species.csv` — small hand-written dimension table mapping each species to its scientific name.
