# 013 · Notes App (Dart / Flutter)

A cross-platform notes app for Android, iOS, macOS, Windows and Linux, with
**full-text search as you type**. Notes autosave, can be pinned and tagged,
and are stored as one JSON file on the device.

The search is a small search engine built from scratch: an inverted index,
prefix matching with binary search, a query language, and TF-IDF ranking.

## Features

- Create, edit, pin and delete notes, with **Undo** after a delete
- Autosave while you type (debounced, so it writes once per pause rather than once per keystroke)
- Blank notes are discarded automatically when you leave the editor
- Tags (`work, ideas`) with filter chips and per-tag counts
- Live search with highlighted matches and a small query language:

  | Query                | Meaning                                             |
  |----------------------|-----------------------------------------------------|
  | `flut sta`           | notes with words starting with `flut` **and** `sta` |
  | `"state management"` | exact phrase (adjacent words)                       |
  | `-redux`             | exclude notes containing `redux`                    |
  | `#work` / `tag:work` | only notes tagged `work`                            |
  | `is:pinned`          | only pinned notes                                   |

- Adaptive layout: list and editor **side by side** on desktop and tablets (≥ 720 px wide),
  list → editor navigation on phones
- Keyboard shortcuts on desktop: **Ctrl/⌘+N** new note, **Ctrl/⌘+F** focus search
- Light and dark themes (Material 3)

## CS concepts demonstrated

| Concept | Where |
|---|---|
| **Inverted index** (term → postings with title/body frequencies), updated incrementally on edit and delete | `lib/src/core/search.dart` – `SearchIndex` |
| **Binary search** (lower bound) over a sorted term dictionary for O(log n) prefix lookup; the dictionary is rebuilt lazily, only when its contents change | `SearchIndex.termsWithPrefix` |
| **TF-IDF ranking** with sub-linear term frequency, a title boost and a penalty for prefix-only matches | `SearchIndex.search` |
| **Tokenization** with Unicode regexes (`\p{L}\p{N}`), keeping character offsets for highlighting | `tokenize`, `highlightRanges` |
| **Query parsing** into a small AST-like structure (terms, phrases, exclusions, filters) | `SearchQuery.parse` |
| **Interval merging** for highlight ranges | `highlightRanges` |
| **Immutable value objects** and structural equality | `lib/src/core/note.dart` |
| **Dependency inversion**: the repository depends on a `NoteStore` interface (JSON file in the app, in-memory in tests); clock and id generator are injected | `note_store.dart`, `note_repository.dart` |
| **Atomic file writes** (write a temp file, then rename it over the original) and versioned file format | `JsonFileNoteStore` |
| **Serialized async writes**: saves are chained so they land in order, and one failed save does not block the later ones | `NoteRepository._save` |
| **Debouncing** user input | `lib/src/ui/note_editor.dart` |
| **Observer pattern** (`ChangeNotifier` + `ListenableBuilder`) and **responsive master-detail** layout | `lib/src/ui/` |

## Project layout

```
lib/
  main.dart                    # wires the JSON store, repository and app together
  notes_core.dart              # exports the pure-Dart core
  src/core/                    # no Flutter imports, so it can be unit-tested with plain Dart
    note.dart                  # Note model, JSON, tag helpers
    note_store.dart            # NoteStore interface, in-memory store, atomic JSON file store
    note_repository.dart       # CRUD, ordering, tags, write-through persistence
    search.dart                # tokenizer, query parser, inverted index, ranking, highlights
    format.dart                # relative-time formatting
  src/ui/
    app.dart                   # MaterialApp and themes
    notes_controller.dart      # ChangeNotifier holding UI state
    home_page.dart             # adaptive list / master-detail, search, tag chips, shortcuts
    note_editor.dart           # editor with debounced autosave and delete/undo
    note_tile.dart             # list row
    highlighted_text.dart      # renders search matches highlighted
test/
  core/                        # unit tests: model, search engine, repository, file store
  widget/app_test.dart         # widget tests: phone and desktop layouts, search, tags, undo
```

```
 UI (Flutter) ──► NotesController (ChangeNotifier)
                        │
                        ▼
                 NoteRepository ──► SearchIndex (inverted index)
                        │
                        ▼
                   NoteStore ◄── JsonFileNoteStore (app) / InMemoryNoteStore (tests)
```

## Build, run and test

This repo contains only the Dart sources. The platform runner folders
(`android/`, `ios/`, `macos/`, …) are generated by Flutter and are git-ignored.

```bash
cd projects/013-notes-app
flutter create . --project-name notes_app --platforms=android,ios,macos,windows,linux
flutter pub get

flutter run -d macos       # or: linux, windows, an emulator, or a connected phone
flutter test               # unit and widget tests
flutter analyze
```

Requires Flutter 3.22 or newer (Dart 3.4 or newer). Notes are stored in
`notes.json` in the platform's application-support directory (from
`path_provider`). The web platform is not supported because the store uses `dart:io`.

### Test status

- **Core unit tests (`test/core/`, 37 tests): passing.** In the environment where this was
  built, the Flutter SDK could not be downloaded, so these were run with the plain Dart SDK
  (3.13). A minimal stand-in for `flutter_test`'s `test`/`expect` API was used. The core has
  no Flutter imports, so it also passed `dart analyze` with strict casts.
- **Widget tests (`test/widget/`, 7 tests)** were written but **not run there**, because they
  need the Flutter SDK. Run `flutter test` to run them.

## Example

```
Search: flut "state management" -redux
┌──────────────────────────────────────────────┐
│ Flutter ideas                         📌     │  ← title matches rank highest
│ state management with riverpod …             │  ← matches highlighted
│ 5 min ago  #work                             │
└──────────────────────────────────────────────┘
```

```json

  "notes": [

```

## Possible extensions

- Markdown rendering and checklists inside notes
- Fold diacritics (`café` → `cafe`) and stem words (`running` → `run`) in the tokenizer
- Typo-tolerant search with Levenshtein automata or a BK-tree
- Store notes in SQLite with FTS5, and compare it with the hand-built index
- Sync across devices with a CRDT so offline edits merge without conflicts
- Encrypt notes at rest with a passphrase-derived key (Argon2 + AES-GCM)
- Web support with an IndexedDB-backed `NoteStore`
