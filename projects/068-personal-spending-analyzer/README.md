# 068 · Personal Spending Analyzer (R)

Turn a bank or credit-card CSV export into a clear picture of where your money goes. The analyzer normalises messy exports, sorts each transaction into a category using prioritised regex rules, and produces a text report plus three PNG charts. The report covers totals by category, monthly cash flow and savings rate, top merchants, budget vs. actual, recurring subscriptions, and unusually large purchases.

Base R does all the work. The only extra package is `testthat`, and only the tests need it.

## Key CS concepts

| Concept | Where |
|---|---|
| **Data normalisation / schema mapping**: column-name aliases, signed vs. debit/credit amounts, multi-format date parsing | `R/io.R` |
| **Rule engine with priority ordering**: first match wins after a stable sort by priority, so specific rules override general ones | `R/categorize.R` |
| **Vectorisation**: loop over the few rules, not the many rows; each rule is one vectorised `grepl` | `categorize()` |
| **Split-apply-combine and pivot tables** using `aggregate`, `tapply` and `split` | `R/analyze.R` |
| **Periodicity detection**: median inter-arrival gap matched to weekly/monthly/yearly periods, plus a coefficient-of-variation check on amounts | `detect_recurring()` |
| **Robust statistics**: median/MAD z-scores flag outliers without letting the outliers distort the baseline | `detect_anomalies()` |
| **Entity resolution (light)**: `merchant_key()` collapses `MEGAMART ONLINE*XY12` and `MEGAMART ONLINE*TV55` into one merchant | `R/io.R` |
| **Data visualisation** with base graphics and a colour-blind-safe (Okabe–Ito) palette | `R/plots.R` |

## Layout

```
R/
  io.R            load + normalise CSVs, parse money/dates, merchant keys
  categorize.R    rule validation and prioritised regex categorisation
  analyze.R       category totals, monthly pivot, cash flow, budgets, recurring, anomalies
  plots.R         PNG charts
  report.R        aligned plain-text report
  load.R          sources the modules (no install needed)
bin/
  analyze.R           CLI
  make_sample_data.R  deterministic fictional data generator
inst/extdata/     sample_transactions.csv, rules.csv, budgets.csv
tests/            testthat suite (78 expectations)
```

## Build, run, test

You need R ≥ 4.1. On Debian/Ubuntu: `apt install r-base-core r-cran-testthat`, or run `make deps`.

```bash
make run      # text report for the bundled sample data
make plots    # also writes output/*.png and output/categorized.csv
make test     # run the test suite
```

To use your own export:

```bash
Rscript bin/analyze.R --rules my_rules.csv --budgets my_budgets.csv \
        --plots charts --out categorized.csv ~/Downloads/statement.csv
```

**Input CSV:** you need a date column, a description column, and either a signed `Amount` column or separate `Debit`/`Credit` columns. Common header names are recognised automatically: *Posted Date*, *Payee*, *Memo*, *Withdrawal*, and so on. Money values like `$1,234.50` and `(12.00)` are parsed.

**Rules CSV:** `pattern,category,priority`. Patterns are case-insensitive Perl regexes, and the lowest priority number wins. Categorise transfers between your own accounts as `Transfer` so they're left out of spending and income.

**Budgets CSV:** `category,monthly_budget`

## Possible extensions

- Learn categories from your manual corrections with a naive Bayes model over description tokens, and keep the rules as overrides.
- Split a transaction across categories (e.g. a big-box receipt that is part groceries, part household).
- Merge multiple accounts and auto-detect matching transfer pairs (same amount, opposite sign, within a few days).
- Rolling 3-month averages and forecasts for each category.
- An interactive Shiny dashboard or a Quarto/R Markdown HTML report.
- Package it properly (`R CMD build`) with roxygen docs.
